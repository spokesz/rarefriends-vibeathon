# Rare Friend Duel

**Builder / contact:** @KingsCritket  
**Category:** Character Spotlight + Token Activity  

**One sentence:**  
A simple mobile-friendly 1v1 battle game where the player fights using their own Rare Friend against an AI opponent, with simulated $RAREFRIENDS items (Potion and Damage Boost).

## What did you build?
A turn-based 1v1 duel game. The player controls their Rare Friend with three actions: Attack, Defend, and Special Ability. There is also a simulated RF shop for Potion and Damage Boost.

## How does it use Rare Friends?
- Designed to use the player's hardwired Generations Friend as the main character.
- Friend artwork is intended to be loaded via FriendSDK.
- Simulated RF spending for items (Token Activity).

## Source repository
https://github.com/kingcritket/rare-friend-duel

## How to run / Playable preview
This is a simplified mobile-first version.  
Source code is available in the repository above (`index.tsx`).

## Controls
- Attack
- Defend
- Special Ability
- Buy Potion (20 simulated RF)
- Buy Damage Boost (30 simulated RF)
