# Friend Errand

* **Project Name:** Friend Errand
* **Builder Name:** Kashif
* **Category:** Character Spotlight / Economy Potential
* **Description:** An interactive web3 mini-game module built for Rare Friends featuring official integration with Friend #335482 and an automated RF token economy.
* **Source Repository:** https://github.com/Kashif1623/friend-errand-vibeathon
* **Playable Preview Link:** https://kashif1623.github.io/friend-errand-vibeathon/
* **How to Use / Play:** Players dispatch their unique on-chain NFT (Friend #335482) on town errands, spending RF tokens to secure randomized rewards, supported by an automated claim faucet.
